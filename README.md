## Overview

Firestone is a Hearthstone companion app built on Overwolf that tracks your deck, opponent's played cards, battle statistics, and arena card picks in real time. It records your match history with detailed replay data and provides tier-list guidance for arena drafts, making it one of the most comprehensive Hearthstone tracking tools available.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Firestone** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Deck Tracker** | Real-time card tracking showing remaining cards in your deck |
| **Opponent Tracking** | Tracks opponent played cards to calculate their remaining hand options |
| **Arena Helper** | Draft guidance with tier ratings for every arena card choice |
| **Match History** | Full match history with detailed replay and statistic breakdowns |
